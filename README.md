# Deepfake Image Classifier — Starter Code

Ye Phase 3 (Image Model) ka starter code hai. Isse chalake aap apna pehla
working deepfake detector bana sakte ho.

```
deepfake_starter/

│   ├── raw/fake/       <- yahan apni FAKE (deepfake) face images daalo
│   ├── train/ val/ test/   <- auto-generated by split_dataset.py

├── src/
│   ├── model.py         <- model architecture
│   ├── dataset.py       <- data loading + augmentation

│   └── predict.py       <- single image ka test
```

## Step-by-Step Setup

### 1. Python environment banao
```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Mac/Linux

pip install -r requirements.txt
```

**GPU check zaroor karo** (RTX GPU use hoga ya nahi, ye confirm karega):
```bash
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```
Agar `False` aaye, toh matlab CUDA-compatible PyTorch install nahi hua —
[pytorch.org](https://pytorch.org/get-started/locally/) se apne CUDA version
ke hisaab se sahi install command lo.

### 2. Folder structure banao
```bash
python setup_folders.py
```

### 3. Dataset dalo
`data/raw/real/` me real face images daalo, `data/raw/fake/` me fake/deepfake
face images daalo. (Dataset kahan se lena hai — next conversation me discuss
karenge: FaceForensics++ / Kaggle subsets.)

Shuru me sirf **1000-2000 images per class** kaafi hain pipeline test karne
ke liye — pura dataset baad me daal sakte ho.

### 4. Train/Val/Test split karo
```bash
python split_dataset.py
```
Ye 70/15/15 split karke `data/train`, `data/val`, `data/test` bana dega.

### 5. Sanity check (optional but recommended)
```bash
python src/model.py       # model load ho raha hai ya nahi check karega
python src/dataset.py     # dataloader sahi se images utha raha hai ya nahi
```

### 6. Training start karo
```bash
python src/train.py
```
- Progress bar dikhega har epoch ke liye.
- Best model automatically `checkpoints/best_model.pth` me save hoga.
- Training khatam hone pe test set ka accuracy/precision/recall/F1/AUC print hoga.

### 7. Single image test karo
```bash
python src/predict.py path/to/some_image.jpg
```
Output: REAL/FAKE verdict + confidence %.

## Configuration (src/train.py ke top pe)
| Setting | Default | Kab badlo |
|---|---|---|
| `EPOCHS` | 15 | Agar val_loss abhi bhi improve ho raha hai, badha do |
| `BATCH_SIZE` | 32 | GPU memory kam hai toh 16 kar do |
| `LR` | 1e-4 | Loss oscillate kare toh chhota karo (5e-5) |
| `PATIENCE` | 4 | Early stopping — kitne epochs tak improve na ho toh rukho |

## Expected Results
Chhote dataset (2000-5000 images/class) pe bhi, pretrained EfficientNet
backbone ke saath **85-92% test accuracy** milna realistic hai. Isse zyada
milta hai toh check karo overfitting toh nahi ho raha (train acc bahut zyada,
val acc kam).
